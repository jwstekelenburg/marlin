# Contributing

This project is published so you can **fork it** and run your own configured copy.

There is **no expectation** that the author will:

- Review or merge pull requests
- Triage or fix issues
- Ship updates on any schedule
- Provide support

Patches and issues may be ignored without comment. If you need a change, keep it in your fork.

See the [README](README.md) (as-is notice) and [LICENSE](LICENSE) (MIT). Operator setup: [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md).
